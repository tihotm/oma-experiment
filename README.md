# OMA7 Experimental Foundation

OMA7 is a minimal experimental control-plane foundation built with reuse-first
rules.

## Current scope

- submission snapshot/identity
- verification-context identity
- evidence applicability
- verifier-on-copy primitive
- SWE-bench baseline contract adapter
- B0 observation normalization
- B0 qualifier
- adversarial tests
- machine-readable upstream pins

## Donors

- `references/SWE-bench`
- `references/attestation`
- `references/witness`

## Status

This repository is intentionally small and evidence-driven. No final architecture
is assumed.
